# BMC Self-Learning Website

Website tự học tương tác **Business Model Canvas (BMC)** dành cho học sinh THPT.

## Cấu trúc
- `index.html` – trang chính
- `styles.css` – giao diện responsive
- `script.js` – tương tác, quiz, progress, Startup Challenge
- `assets/` – hình ảnh lấy từ PowerPoint nguồn

## Đưa lên GitHub Pages
1. Tạo một repository mới trên GitHub.
2. Upload toàn bộ **nội dung bên trong thư mục này** lên branch `main`.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`, rồi **Save**.
6. Sau vài phút, GitHub sẽ cung cấp URL của website.

Website dùng HTML/CSS/JavaScript thuần, không cần cài thư viện hay build.
